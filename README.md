## Projeto em destaque

Projeto acadêmico voltado ao **monitoramento de fluxo de água**, integrando sensores, Arduino e uma aplicação para acompanhar os dados e sinalizar a ausência de fluxo.

**O que esse projeto conecta:** programação, aquisição de dados, comunicação entre hardware e software e visualização de informações.
